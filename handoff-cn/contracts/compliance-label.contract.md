# Contract · 合规标识与转人工（FIXTURE）

| 项 | 定义 |
|---|---|
| 输入 | `{asset_type, content, user_request_unmarked, agreement_confirmed}` |
| 输出 | `{explicit_mark, implicit_meta, log_retention_days, handoff_required, reason}` |
| 显式标识 | 文本/图片/音频/视频等生成内容在界面或内容中添加可感知标识 |
| 隐式标识 | 文件元数据写入生成合成属性、传播平台名称或编码、内容编号 |
| 去标识申请 | 仅在用户协议明确义务与责任后提供，并留存提供对象信息日志不少于六个月 |
| 转人工条件 | 用户明确要求、复杂纠纷、资金争议、人身财产安全风险 |
| 人工最终确认 | 价格、退款、赔偿等关键事项不得由 AI 单独承诺 |
| 会话切换 | 完整传递交互记录，不得要求用户重复陈述 |
| 备案检查 | 无备案引用时阻塞上线并列出材料清单 |
| 禁止行为 | 恶意删除、篡改、伪造、隐匿标识；以"算法自动生成"推卸责任 |
